# QR Studio Pro - เว็บสร้าง QR Code ฟรี ครบทุกรูปแบบ

เว็บแอปพลิเคชันสำหรับสร้าง QR Code แบบ Standalone 100% Client-Side ที่ทำงานได้จริง สวยงามทันสมัย ใช้งานง่าย และเซฟรูปภาพคุณภาพสูงได้ทันที

---

## ✨ จุดเด่นและฟีเจอร์หลัก (Features)

### 1. 🌐 รองรับประเภทข้อมูลหลากหลาย
- **URL / ลิงก์เว็บไซต์**: สแกนเพื่อเปิดเว็บไซต์, ลิงก์โซเชียลมีเดีย (Facebook, IG, TikTok, YouTube)
- **WiFi**: สแกนเพื่อต่อสัญญาณ WiFi ทันที ไม่ต้องพิมพ์รหัสผ่าน (รองรับ WPA/WPA2/WPA3, WEP, เครือข่ายเปิด และ Hidden SSID)
- **PromptPay (พร้อมเพย์)**: สร้าง QR พร้อมเพย์ตามมาตรฐาน EMVCo ของธนาคารแห่งประเทศไทย สแกนจ่ายผ่านทุกแอปธนาคารไทยได้จริง (รองรับทั้งเบอร์มือถือและเลขบัตรประชาชน พร้อมระบุจำนวนเงินได้)
- **ข้อความ (Text)**: ข้อความตัวหนังสือภาษาไทยและอังกฤษ โน้ต รหัส หรือข้อความทั่วไป
- **นามบัตร (vCard)**: สแกนเพื่อบันทึกข้อมูลผู้ติดต่อลงโทรศัพท์ (ชื่อ, เบอร์, อีเมล, บริษัท, ตำแหน่ง, เว็บไซต์)
- **อีเมล (Email)**: สแกนเพื่อเปิดแอปเมลพร้อมกรอกที่อยู่อีเมล หัวข้อ และเนื้อหา
- **เบอร์โทรศัพท์ (Tel)**: สแกนเพื่อกดโทรออกทันที
- **SMS**: สแกนเพื่อเปิดหน้าส่งข้อความ SMS

### 2. 🎨 ปรับแต่งดีไซน์ได้อิสระ (Customization)
- **สี QR Code & สีพื้นหลัง**: เลือกสีได้อิสระผ่าน Color Picker พร้อมตัวเลือกรหัส HEX
- **พื้นหลังโปร่งใส (Transparent Background)**: สำหรับนำไปแปะบนโปสเตอร์ งานกราฟิก หรือวิดีโอ
- **จานสียอดนิยม (Color Presets)**: Classic Noir, Indigo Modern, Cyber Cyan, Emerald Leaf, Crimson Red, Royal Purple
- **ปรับความละเอียด (Resolution)**: ตั้งแต่ 256px จนถึง 2048px สำหรับงานพิมพ์ความละเอียดสูง คมชัด ไม่แตก
- **ปรับระยะขอบ (Margin / Quiet Zone)**: ปรับได้ตั้งแต่ 0 ถึง 6
- **ใส่โลโก้ตรงกลาง (Logo Center)**:
  - มี Preset โลโก้สำเร็จรูป: Link, WiFi, PromptPay, Star, Heart
  - **อัปโหลดโลโก้ของตัวเอง**: สามารถเลือกรูปภาพ PNG, JPG, SVG หรือ WebP มาแสดงตรงกลาง QR Code ได้ โดยระบบจะปรับ Error Correction เป็นระดับ High (H - 30%) ให้อัตโนมัติเพื่อให้สแกนติดง่าย 100%

### 3. 📥 บันทึกและส่งออกรูปภาพ (Export Options)
- **ดาวน์โหลด PNG**: ความละเอียดสูงตามที่ตั้งค่า
- **ดาวน์โหลด JPEG**: เหมาะสำหรับส่งต่อหรือลงแพลตฟอร์มต่างๆ
- **ดาวน์โหลด SVG**: เวกเตอร์ คมชัดไม่แตก ไม่ว่าจะขยายขนาดใหญ่แค่ไหน เหมาะกับงานป้าย ไวนิล หรืองานพิมพ์มืออาชีพ
- **คัดลอกรูปภาพ (Copy to Clipboard)**: กดปุ่มเดียว คัดลอกรูปภาพลงคลิปบอร์ด แล้วกด `Ctrl + V` หรือ `Cmd + V` วางในแชท Line, Facebook หรือโปรแกรมกราฟิกได้ทันที
- **พิมพ์ (Print)**: ปริ้นต์ QR Code ออกทางเครื่องพิมพ์ได้ทันที

### 4. 💻 ดีไซน์โมเดิร์น & ใช้งานได้จริง
- **Offline 100%**: ไม่พึ่งพาเซิร์ฟเวอร์ ข้อมูลส่วนตัวของคุณไม่ถูกส่งออกนอกเครื่อง
- **Dark Mode / Light Mode**: มีปุ่มสลับธีมพร้อมบันทึกสถานะ
- **ประวัติการสร้างล่าสุด (Recent History)**: บันทึก QR Code ที่เคยสร้างล่าสุด กดย้อนดูหรือดาวน์โหลดซ้ำได้ตลอดเวลา
- **Responsive**: ใช้งานได้สะดวกทั้งบนหน้าจอคอมพิวเตอร์ แท็บเล็ต และสมาร์ตโฟน

## 🚀 วิธีเปิดใช้งาน (How to Run)

สามารถเปิดใช้งานได้ 2 วิธีง่ายๆ:

### วิธีที่ 1: ดับเบิลคลิกเปิดไฟล์โดยตรง (แนะนำ ง่ายที่สุด)
- ดับเบิลคลิกที่ไฟล์ `index.html` เพื่อเปิดใช้งานบน Google Chrome, Safari, Edge, หรือ Firefox ได้ทันที โดยไม่ต้องลงโปรแกรมใดๆ เพิ่มเติม

### วิธีที่ 2: รันผ่าน Local Web Server (ถ้าต้องการ)
เปิด Terminal ในโฟลเดอร์นี้ แล้วรันคำสั่ง:
```bash
python3 -m http.server 8080
```
จากนั้นเปิดเบราว์เซอร์ไปที่: `http://localhost:8080`
